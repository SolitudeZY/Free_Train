# Free-Train 界面与交互设计

## 1. 设计目标

- 视觉上接近现代 Windows 专业工具，而不是默认桌面控件集合。
- 高频流程可快速完成，复杂参数需要时才展开。
- 大量素材、缩略图和任务状态下保持稳定布局。
- 自动建议、人工决策和源素材状态必须一眼可区分。
- 视频人工筛查、ROI 操作和相似图审核尽量减少鼠标移动。

## 2. 应用框架

```text
┌ Free-Train / 项目名称                    导入  预估  快速处理  导出 ┐
├──────────────┬──────────────────────────────┬───────────────────┤
│ 项目与素材    │                              │ 当前工具/参数      │
│              │       主预览或审核区域        │                   │
│ 来源组        │                              │ 抽帧 / ROI / 质检  │
│  cam1_01     │                              │ 相似 / 增强 / 命名 │
│   video.mp4  ├──────────────────────────────┤                   │
│  cam2_01     │ 缩略图、时间轴或对比区域      │ 实时估算与警告      │
├──────────────┴──────────────────────────────┴───────────────────┤
│ 任务：处理中 68%   保留 1,824   建议排除 316   错误 2   磁盘 42GB │
└──────────────────────────────────────────────────────────────────┘
```

### 2.1 区域职责

- 顶部工具栏：导入、预估、快速处理、取消、审核、导出。
- 左侧导航：项目、来源组、源素材、流程视图和已保存预设。
- 中央工作区：视频播放器、图片预览、切片预览、审核网格或对比视图。
- 右侧检查器：当前工具参数、阈值、命名模板和实时估算。
- 底部状态区：任务、阶段、数量、错误、内存和磁盘状态。

面板支持拖动调整。建议最小窗口为 1100×700；宽度不足时右侧检查器可折叠为抽屉，不能覆盖主要操作按钮。

## 3. 信息架构

左侧主导航使用五个工作区：

1. **素材**：导入、分组、来源标识、元数据和离线重连。
2. **处理**：视频筛查、抽帧、ROI、切图、质量和相似参数。
3. **审核**：候选网格、相似组、质量警告和人工决策。
4. **导出**：增强配方、命名模板、冲突检查、导出计划。
5. **任务**：队列、进度、错误、恢复和历史报告。

它们是可往返的工作区，不是必须从头走到尾的向导。

## 4. 素材工作区

### 4.1 素材树

- 第一层显示来源组。
- 第二层显示视频、图片目录或单文件。
- 状态图标区分正常、处理中、离线、警告和失败。
- 文件名、来源标识、分辨率和时长在稳定列中显示。
- 支持多选后批量应用 ROI、抽帧或命名预设。

### 4.2 素材详情

- 基本信息：路径、大小、类型、分辨率、时长、编码、帧率。
- 时间信息：内嵌时间、文件名解析结果、文件系统时间和最终拍摄时间来源。
- 指纹信息：快速指纹、完整 SHA-256 状态。
- 来源映射：相对目录、来源组、来源标识。
- 离线状态提供“重新定位”主操作。

## 5. 视频人工筛查工作台

```text
┌──────────────────────── 视频画面 ────────────────────────┐
│                ROI 边框、切片网格和当前坐标              │
└───────────────────────────────────────────────────────────┘
 00:02:13.400  ───●─────[有效片段]────▲人工帧──── 00:18:20
 [上一帧] [播放] [下一帧] [保存当前帧] [设入点] [设出点]
 播放速度 0.25x 0.5x 1x 2x   跳转时间 [            ]
```

### 5.1 交互

- 拖动时间轴时优先显示低分辨率预览，停止拖动后加载精确帧。
- “上一帧/下一帧”按实际解码帧移动，不按固定 FPS 推算。
- “保存当前帧”立即添加人工抽帧标记，并显示锁定状态。
- 入点与出点形成有效片段；多个片段使用不同轨道避免覆盖。
- 变化曲线可折叠显示，自动抽帧时间点以独立标记呈现。
- 同一精确时间戳重复保存时提示已存在，而不是生成重复记录。

### 5.2 推荐快捷键

- `Space`：播放/暂停。
- `Left` / `Right`：上一帧/下一帧。
- `C`：保存当前帧。
- `I` / `O`：设置有效片段入点/出点。
- `[` / `]`：跳转上一个/下一个标记。

快捷键可配置，文本输入控件获得焦点时不得误触。

## 6. ROI 与切图工作台

- 中央画面直接拖拽新建和调整矩形 ROI。
- ROI 使用名称和颜色区分，选中时显示八个缩放控制点。
- 右侧提供 X、Y、宽、高精确输入及边界校验。
- 切片预览显示行列编号、输出尺寸、重叠区和边缘处理结果。
- 多来源批量应用前显示“共应用到 N 个来源”，并允许来源级覆盖。
- 切片数量、预计图片量和预计磁盘占用实时更新。

## 7. 质量与相似参数

### 7.1 质量阈值

- 每个指标使用启用开关、阈值输入和分布小图。
- 选中指标后，中央区域展示阈值两侧代表样本。
- 右侧持续显示“预计新增建议排除 N 张”，但修改阈值不立即覆盖人工决策。

### 7.2 相似度

- 普通模式：严格、平衡、宽松分段控件和相似度滑块。
- 高级模式：pHash 距离、SSIM 阈值、时间窗口和比较范围。
- 跨来源、跨 ROI 或跨切片比较使用警告色，并要求显式确认。

## 8. 审核工作台

### 8.1 缩略图网格

- 固定缩略图宽高比和稳定网格尺寸。
- 建议排除项覆盖浅白色半透明蒙层。
- 左上角显示选择状态，右上角显示锁定、质量警告或失败图标。
- 底部紧凑显示来源、视频偏移或文件名。
- 虚拟滚动只渲染可见区域及少量预取内容。

### 8.2 相似组模式

- 代表图在组内使用绿色边框，不使用大面积绿色背景。
- 支持点击更换代表图、整组保留和排除选中。
- 双击进入并排对比，缩放和拖动可同步。
- 多个锁定候选图处于同组时显示明确冲突状态。

### 8.3 状态颜色

- 保留：绿色边线或图标。
- 建议排除：浅白蒙层和灰色状态。
- 人工排除：更明确的灰色/红色小标记，不遮挡整个画面细节。
- 警告：橙色。
- 错误：红色。
- 锁定：蓝色锁图标。

颜色不能作为唯一信息来源，必须配合图标和文本提示。

## 9. 增强配方工作台

- 左侧为有序操作列表，可拖动改变顺序。
- 每个操作显示启用开关、概率和参数范围。
- 中央以 2×2 或 3×2 网格显示同一候选图的随机预览。
- 顶部固定显示随机种子和变体数量。
- 风险操作显示内联警告，例如垂直翻转可能破坏重力语义。
- 未安装高级执行器时，相关操作显示“需要可选增强包”，不能伪装为可运行。
- 明确显示增强后预计图片总数和标注工作量提醒。

## 10. 命名与导出工作台

### 10.1 模板编辑器

- 字段通过菜单插入，模板本身使用可编辑文本表达式。
- 字段可设置格式，例如时间格式和序号位数。
- 下方持续显示至少 5 个真实文件名示例。
- 不可用字段、非法字符、过长路径和重名在执行前显示。

### 10.2 导出确认

- 输出根目录。
- 干净导出或增强导出。
- 文件格式和质量。
- 保留/排除/失败数量。
- 预计图片数、预计空间和可用磁盘。
- 重名策略。
- JSONL/CSV 清单选项。

“确认并导出”是最终明确命令，不能与普通“保存预设”混淆。

## 11. 任务工作区

- 顶部显示运行中、排队、等待审核、完成但有错误等分组。
- 单任务显示阶段进度和来源级子进度。
- 错误列表可按来源和阶段过滤，并提供重试入口。
- 中断任务显示“恢复”而不是重新开始。
- 缓存清理显示目标目录、预计释放空间和受影响阶段。

## 12. 快速处理

- 用户选择处理预设和素材后点击“快速处理”。
- 执行前弹出轻量确认层，显示预计输出和磁盘，而不是多页向导。
- 处理完成后自动切换到审核工作区。
- 自动建议不会直接导出或清理缓存。
- 没有候选图、全部失败或磁盘不足时使用专门结果状态，不显示空白页面。

## 13. 视觉系统

### 13.1 色彩

- 浅色背景：接近中性白和浅灰，不使用米色主题。
- 深色背景：中性炭灰，避免整页深蓝或紫色。
- 主操作：克制蓝色。
- 成功/保留：绿色。
- 警告：琥珀色。
- 错误：红色。

### 13.2 尺寸

- 基础间距：4px 网格。
- 常用控件高度：28-34px。
- 工具栏图标按钮：32×32px，尺寸固定。
- 面板标题：14-16px，不使用超大字号。
- 卡片和弹窗圆角：4-8px。
- 字符间距固定为 0。

### 13.3 图标

- 使用 Lucide 图标。
- 保存当前帧、播放、逐帧、锁定、恢复、排除、缩放、导入和导出均使用熟悉图标。
- 不手绘重复 SVG 图标。

## 14. 状态与可访问性

- 加载状态使用稳定占位，不改变父容器尺寸。
- 空状态只描述当前缺失内容和一个明确操作，不展示营销文案。
- 错误信息包含发生位置、原因和可执行下一步。
- 所有图标按钮提供工具提示和可访问名称。
- 关键操作支持键盘焦点和明显焦点边框。
- 浅白排除蒙层在浅色与深色主题下都必须保留足够可辨识度。
