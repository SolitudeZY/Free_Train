# M4 阶段门禁评审

评审基线：`main` / `18d0671`

评审结论：M4 已进入收尾阶段，质量、相似、审核和审核后导出的核心纵向流程可用，但当前不满足正式进入 M5 的门禁。

## 1. 已达到的验收条件

### AC-007：质量阈值与源素材保护

状态：通过实现与自动化验证，待最终人工窗口验收。

- 可调整分辨率、清晰度、欠曝、过曝和低信息量阈值。
- 提供阈值分布、阈值附近样本和预计影响数量。
- 自动结果仅写入项目审核状态，不物理删除或改写源素材。
- 自动化测试验证分析、审核和导出前后源素材 SHA-256 不变。

### AC-008：相似组、建议排除与恢复

状态：核心行为通过实现与自动化验证，待大规模正式工作台验收。

- 支持 SHA-256 精确重复、pHash 召回、SSIM 确认和相似连通组。
- 支持建议排除蒙层、相似分数、代表图、恢复、人工保留/排除和撤销/重做。
- 支持相似组并排对比、同步缩放/平移和组级代表图切换。
- 自动化测试覆盖人工决定持久化、锁定优先、代表图重算和导出资格。

### AC-009：人工抽帧默认锁定

状态：通过实现与自动化验证。

- 人工保存帧默认 `pinned=true`。
- 审核分析将人工帧映射为锁定项；自动重算优先选择锁定代表图。
- 自动规则不会使锁定帧失去导出资格，除非用户显式人工排除。

## 2. 未达到的退出条件

### AC-015：快速处理停在审核阶段

状态：未通过，属于进入 M5 前的阻塞项。

当前顶部命令是“质量审核”，只对现有静态图片和视频候选执行质量与相似分析。它尚未按保存预设串联：

1. 输入校验与数量估算。
2. 视频抽帧或静态图片接入。
3. ROI 合并与切片准备。
4. 质量分析与相似分组。
5. 停在审核工作台，等待用户确认。

在该流程交付前，不应把“质量审核”重新命名为“快速处理”，也不能认定 `AC-015` 通过。

### 切片级审核数据模型

状态：未实现，属于进入 M5 前的阻塞项。

- 仓库中没有正式的 `prepared_images` 表、实体和迁移。
- 当前切片预览和导出计划可重建，但不能形成稳定、可恢复、可审计的切片级审核资产。
- M5 的增强血缘与完整追溯需要稳定的输入成品标识；若跳过该模型直接开发 M5，后续需要重写增强和清单关联。

### 正式审核工作台虚拟滚动

状态：未实现，属于 M4 规模门禁。

- 当前审核页每次取前 400 项，通过“加载更多”扩大数组切片。
- M0 的 `/m0/virtual-grid` 已验证 100,000 项窗口化技术，但尚未移植到正式审核工作台。
- 需要完成 100,000 候选的滚动、筛选、选择保持和内存基线。
