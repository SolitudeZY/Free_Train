# M5 增强、命名和追溯导出实现报告

当前状态：进行中。第一条纵向交付已完成版本化增强配方、固定种子基础增强预览和逐变体溯源；正式增强导出、完整命名与 JSONL/CSV 追溯导出仍待后续交付。

## 本次交付

- M4 真实素材人工验收已由用户确认通过，阶段正式关闭。
- Schema 升级至版本 7，新增 `augmentation_recipes` 与 `augmentation_previews`。
- 增强输入严格使用审核工作台中的 `prepared_images.asset_key`，拒绝普通源图/候选帧和人工排除切片。
- `rust-basic-v1` 执行器支持亮度、对比度、水平翻转、顺时针 90° 旋转。
- 每个操作支持启用、概率和参数范围，按配方数组顺序执行。
- 每张切片支持 1-16 个变体，基础种子与资产键、变体序号共同派生实际 64 位种子。
- 每个预览记录输入资产键、配方版本、变体序号、实际种子、实际执行参数、执行器版本、`lineage_group_id` 和内容 SHA-256。
- 增强预览只写入项目缓存，不修改源素材，也不接入当前正式导出。
- 审核侧栏新增“增强预览”工作区，显示变体图片、种子、血缘组和实际参数；字体沿用 M4 已提高的可读基线。
