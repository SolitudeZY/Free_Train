# M2 视频抽帧与人工筛查实现报告

## 状态

- 日期：2026-07-22
- 结论：M2 可用纵向流程已实现，待人工窗口验收
- 下一阶段：M3 ROI、切图与基础导出

## 1. 已实现

### 1.1 轻量视频时间轴

- 选择视频时只使用已有的时长和平均帧率元数据，不再枚举整段视频的全部帧时间戳。
- 上一帧和下一帧按媒体平均帧率定位，避免长视频产生大型 Rust/JSON/JavaScript 时间戳数组。
- 支持播放、暂停、0.25x、0.5x、1x、2x、时间轴拖动和精确时间跳转。
- 支持 `Space`、左右方向键、`C`、`I`、`O` 快捷键；输入控件获得焦点时不触发。
- 候选图支持 `A/D`、小键盘 `4/6` 和方括号键前后切换，左右方向键仍专用于逐帧定位。

### 1.2 人工抽帧

- 当前播放器时间直接作为候选时间点，由 FFmpeg 快速精确寻帧并重新解码保存，不使用 WebView 截图。
- 保存源素材、视频内偏移、可靠的源帧编号、选择方式和参数快照。
- 人工候选默认锁定。
- 同一源视频同一时间戳重复保存时复用原记录，并升级为人工锁定状态。
- 候选原图和缩略图保存在项目缓存目录，不修改源视频。

### 1.3 有效片段

- 时间轴支持入点、出点和多个有效片段。
- 有效片段持久化到 SQLite，重开项目后恢复。
- 可删除片段并跳转到片段开始位置。
- 可指定新片段产生的批量候选默认锁定。

### 1.4 自动抽帧

- 固定时间间隔。
- 固定帧间隔。
- 目标数量均匀抽取。
- 一个或多个有效片段内按时间间隔抽取。
- 画面变化触发抽帧。
- 固定时间、目标数量、有效片段和变化触发直接按时间规划并去重，不展开完整帧列表。
- 固定帧间隔使用媒体平均帧率计算源帧编号和时间点，并限制计划最多 100,000 张。
- 单视频执行支持预估、新增/已存在/失败数量统计。

### 1.5 画面变化分析

- FFmpeg 将视频流式降采样为 160 像素宽灰度帧。
- Rust 计算相邻分析帧的归一化平均绝对差异。
- 支持分析 FPS、变化阈值、最小间隔和最大兜底间隔。
- 右侧显示客观变化分数曲线和建议时间点数量，并标注视频时间、变化分数、刻度和当前阈值。
- 变化结果只用于选择候选时间点，不描述为 AI 事件识别。

### 1.7 反馈修正

- 右侧素材信息和抽帧面板字号整体提高，保持工作区紧凑度的同时提升可读性。
- FFmpeg 与 ffprobe 子进程在 Windows 使用 `CREATE_NO_WINDOW`，导入、分析和抽帧静默执行。
- 预估完成后，右侧预估卡、底部候选计数和候选缩略图区闪烁两次，突出预计候选数量。
- 长视频单帧提取将 `-ss` 放在输入之前，只解码目标附近的 GOP，并限制为单解码线程。
- 当前选中的长视频使用自动缓冲以支持远距离 seek；不兼容 WebView2 的 HEVC 等编码在后台生成 960×540、30 fps 的 H.264 项目缓存，原视频仍用于抽帧和导出。
- 兼容预览限制为单 CPU 编码线程，生成后抽样校验首帧、中间帧和末尾帧；缓存损坏时自动丢弃并重建。
- 视频源不在导入后执行后台全文件 SHA-256，避免预览和抽帧期间争抢磁盘。
- 左右方向键连续触发时只保留一个进行中的 seek 和最新目标帧，避免 WebView2 解码队列积压。
- 固定时间间隔和固定帧间隔抽帧使用单个 FFmpeg 进程顺序解码并批量输出，避免上千次进程启动与随机 seek；硬件解码不可用时自动回退到单线程软件解码。
- 抽帧和正式导出通过 Tauri 事件逐项上报进度、成功数、已有/跳过数和失败数，长任务期间界面保持可见反馈。
- 抽帧预估区分计划总数、已有候选和预计新增；中断后重跑对相差 1ms 的时间戳舍入结果按同一候选处理，避免 `1.999s` / `2.000s` 近重复持续累积。
- 抽帧完成后显示明确的流程交接卡：用户可选择“先审核再导出”或“直接导出”，不会被强制运行耗时审核。
- 30 分钟、160×90、30 FPS 基准中，第 29 分钟单帧提取由 2.826 秒降至 0.470 秒，约快 6 倍。
- 正式导出仍属于 M3；M2 候选原图保存在 `.ftproj/cache/candidates`，作为项目内部中间数据。

### 1.6 来源组批量处理

- 固定时间、固定帧间隔和目标数量模式可应用于当前来源组全部视频。
- 批量预估显示视频数量和候选总数。
- 单视频失败只进入失败列表，不中断同来源组其他视频。
- 有效片段和变化触发保持来源级执行，避免错误复用时间段或变化点。

## 4. 人工验收重点

- 视频画面点击、播放按钮和空格键均能播放/暂停。
- 左右方向键和逐帧按钮移动到相邻实际帧。
- 保存当前帧后底部出现带锁定图标的候选缩略图。
- 重复保存同一时间点不增加候选数量。
- 入点/出点在时间轴显示绿色片段带。
- 五种抽帧模式的预估数量合理，执行后候选缩略图可跳回源视频时间点。
- 画面变化曲线能够生成，最大兜底间隔会在静态片段保留稀疏样本。
- 关闭并重开项目后候选和片段仍存在。

## 5. 保留项

- 可变帧率视频的逐帧按钮和固定帧间隔模式目前按平均帧率定位；如需编辑级逐帧精度，后续增加按需局部时间戳查询，而不恢复全量索引。
- 有效片段目前支持创建、跳转和删除；拖拽移动与边界数值编辑将在后续交互迭代补充。
- 抽帧执行当前按来源串行，任务级进度、取消和中断恢复由 M6 任务引擎统一接管。
- 浏览器播放器用于交互定位，最终候选始终由 FFmpeg 解码；极端编码格式仍以发行版 FFmpeg 能力清单为准。
