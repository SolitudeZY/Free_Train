# Free-Train 实施计划

## 1. 计划说明

本计划以一名熟悉 Rust、TypeScript 和桌面应用的工程师为参考。工作量是人周范围，不是日历承诺；媒体兼容性、FFmpeg 精简构建和 Windows 打包可能影响实际周期。

桌面 MVP 预计约 14-18 人周。MCP、Albumentations 高级扩展和完整离线安装包不计入 MVP。

## 2. 实施原则

1. 每个里程碑交付可运行的纵向流程。
2. 先验证高风险技术，再扩大功能面。
3. 预览与最终处理共用核心算法，禁止两套逻辑。
4. 每个任务阶段同时实现取消、错误隔离和结构化日志。
5. 数据库迁移、参数版本和追溯记录从第一个版本开始存在。
6. 不以临时代码绕过源素材不可变、路径边界和人工审核规则。

## 3. 里程碑总览

| 里程碑 | 目标 | 参考工作量 | 可交付结果 |
|---|---|---:|---|
| M0 | 技术验证与仓库初始化 | 1-2 人周 | 风险验证报告、可启动空壳 |
| M1 | 项目、素材与基础预览 | 2 人周 | 可导入并查看视频/图片 |
| M2 | 视频抽帧与人工筛查 | 2-3 人周 | 自动和手动抽帧可用 |
| M3 | ROI、切图与基础导出 | 2 人周 | 第一条完整预处理纵向切片 |
| M4 | 质量、相似与审核 | 3 人周 | 可审核建议排除和代表图 |
| M5 | 增强、命名和追溯导出 | 2-3 人周 | 完整 MVP 功能闭环 |
| M6 | 恢复、性能、安装与发布 | 2-3 人周 | 内部可发布版本 |
| M7 | MCP 与高级增强 | MVP 后 | 独立后续版本 |

## 4. M0：技术验证与仓库初始化

### 4.1 目标

尽早验证会改变架构或安装体积的风险，不在完整实现后才发现阻塞。

### 4.2 工作项

- 初始化 Rust workspace、Tauri 2、Svelte、TypeScript 和基础 CI。
- 建立 `domain`、`application`、`storage`、`media`、`image-pipeline`、`job-engine` crate。
- 建立统一错误 DTO、事件协议和日志格式。
- 验证 WebView2、拖放、原生文件对话框和中文路径。
- 生成精简 FFmpeg/ffprobe 原型，验证 H.264、H.265、MOV、MP4 和变帧率视频。
- 验证指定时间抽帧、逐帧移动和实际时间戳误差。
- 验证 Rust ROI、缩放、切片、pHash、SSIM 和基础增强库。
- 用 100,000 条虚拟记录验证 SQLite 分页和 Svelte 虚拟网格。
- 建立第三方许可证清单和 FFmpeg 构建参数记录。
- 记录 ADR 或更新现有 ADR，说明任何偏离当前方案的决定。

### 4.3 退出条件

- 空壳应用在 Windows 10/11 启动。
- 标准开发构建不携带 Python、Qt、OpenCV、Node.js 或 Chromium 运行时。
- 精简 FFmpeg 能正确探测和抽取代表性测试视频。
- 100,000 条缩略图元数据的虚拟网格可滚动且内存稳定。
- 已确认预期发布包仍有机会控制在 40-70 MB；若不满足，先更新 PRD 和 ADR 再继续。

## 5. M1：项目、素材与基础预览

### 5.1 纵向场景

用户创建项目，拖入视频和图片目录，在素材树中查看元数据、来源组、来源标识和预览，关闭并重新打开项目后状态保持。

### 5.2 工作项

- SQLite 初始迁移和项目锁。
- 项目创建、打开、最近项目和数据库备份。
- 原地引用导入和递归目录扫描。
- 快速指纹、后台完整 SHA-256 和离线状态。
- ffprobe 元数据、图片元数据和 EXIF 方向。
- 来源组和来源标识映射。
- 拍摄时间证据来源和文件名解析规则基础版。
- 视频播放器和图片预览。
- 缩略图缓存和优先级队列。
- 离线素材重新定位。

### 5.3 测试

- 中文、空格和长路径。
- 素材移动、替换、损坏和重复导入。
- 项目重开、数据库迁移和异常关闭。
- 源素材处理前后哈希不变。

### 5.4 退出条件

- PRD `AC-002` 的素材导入和离线恢复部分通过。
- 一个损坏文件不会阻塞同目录其他素材。
- UI 在 10,000 个素材条目下仍使用分页或虚拟化。

## 6. M2：视频抽帧与人工筛查

### 6.1 纵向场景

用户播放一个变帧率视频，逐帧定位运动物体并保存精确帧；同时标记多个有效片段并按配置批量抽帧。

### 6.2 工作项

- 固定时间间隔、固定帧间隔、目标数量和时间范围抽帧计划。
- 变帧率时间戳处理。
- 播放、暂停、逐帧、变速和时间跳转。
- 人工抽帧标记、默认锁定和重复时间点检查。
- 有效片段入点/出点、编辑和多段轨道。
- 有效片段按 FPS、时间间隔、帧间隔抽取。
- 画面变化分析、变化曲线、最小间隔和最大兜底间隔。
- 全画面、单 ROI 或 ROI 并集分析接口。
- 抽帧预估和任务事件。

### 6.3 测试

- 固定帧率和变帧率视频。
- 短时运动、长静态片段和多个变化峰值。
- 人工抽帧精确时间戳。
- 有效片段交叠、无效入出点和重复标记。
- 抽帧期间取消和应用退出。

### 6.4 退出条件

- PRD `AC-003`、`AC-004`、`AC-005` 通过。
- 人工抽帧在质量或相似阶段重算后仍保持锁定。
- 变化曲线预览和最终抽帧时间点来自同一计划。

## 7. M3：ROI、切图与基础导出

### 7.1 纵向场景

用户为两个不同摄像头配置不同矩形 ROI，将候选帧切成统一大小，预览文件名后导出图片和来源清单。

### 7.2 工作项

- 多命名矩形 ROI 编辑器。
- 来源组预设和来源级覆盖。
- 固定宽高、横纵重叠和三种边缘策略。
- 常量、边缘复制和反射填充。
- 缩放、适配、填满和长短边策略。
- 切片坐标、行列编号和预览。
- 基础命名模板 AST、非法字符和序号。
- JPEG、PNG、WebP 基础导出。
- JSONL 来源清单。
- 临时文件和原子重命名。

### 7.3 测试

- 随机 ROI 和切图属性测试。
- 混合分辨率、EXIF 旋转和视频旋转。
- 边缘不足、重叠 0% 和高重叠率。
- Windows 保留文件名、长路径和重名。
- 导出中断和磁盘不足。

### 7.4 退出条件

- PRD `AC-006`、`AC-010`、`AC-011` 的基础路径通过。
- 预览切片坐标与最终导出清单完全一致。
- 源素材和项目数据库不在缓存清理目标中。

## 8. M4：质量、相似与审核

### 8.1 纵向场景

用户运行质量和相似分析，在虚拟缩略图网格中查看浅白蒙层建议排除项、相似组和代表图，并恢复或锁定任意图片。

### 8.2 工作项

已交付：

- [x] 解码、分辨率、宽高比、清晰度、曝光和低信息量指标。
- [x] 项目级 SHA-256 精确重复、pHash 候选检索和 SSIM 临界确认。
- [x] 同来源、来源组和全项目比较范围，以及视频时间窗口安全限制。
- [x] 相似图连通组、质量评分代表图、锁定优先和多锁定冲突提示。
- [x] 审核状态、人工保留/排除/恢复、锁定/解锁、更换代表图、审计事件和持久化撤销/重做。
- [x] 分段审核网格、浅白建议排除蒙层、状态/来源/相似组筛选和批量操作。
- [x] 快速处理直接运行质量与相似分析并进入审核工作台。

待交付：

- [x] 阈值分布、阈值附近代表样本、预计影响数量预览和质量指标排序。
- [x] 相似组并排对比与同步缩放。
- [x] 代表图切换的组级撤销/重做。
- [x] 质量指标排序。
- [ ] 更大规模虚拟滚动。
- [ ] 基于 `prepared_images` 的切片级审核。
- [ ] 将快速处理串联至抽帧、ROI/切图、质量和审核的完整流水线。

### 8.3 测试

- [x] 质量指标、精确重复、相似组、锁定代表图和人工状态重算保留。
- [x] 人工排除导出跳过与源素材 SHA-256 不变。
- [x] 来源删除进度事件、重新导入和原文件保留。
- [ ] 黄金图片对和算法版本固定样本。
- [ ] 同位置/不同位置切片比较边界。
- [ ] 100,000 候选图虚拟滚动、筛选和内存基线。

### 8.4 退出条件

- PRD `AC-007`、`AC-008`、`AC-009`、`AC-015` 通过。
- 相同输入和版本重复运行产生相同相似组和代表图。
- 所有排除操作均为项目状态，不删除源素材。

## 9. M5：增强、完整命名和追溯导出

### 9.1 纵向场景

用户创建增强配方，预览固定种子的多个变体，使用自由命名模板执行增强导出，并通过清单追溯每个变体。

### 9.2 工作项

- Rust 增强执行器和版本化配方 Schema。
- 几何、光照、颜色、模糊、噪声、压缩和基础环境效果。
- 概率、范围、顺序、变体数量和随机种子。
- 风险操作提示和标注量提示。
- `lineage_group_id` 与执行参数记录。
- 完整命名字段、拍摄时间证据和来源映射。
- 文件名实时示例和全量冲突扫描。
- JSONL/CSV 清单、任务报告和内容哈希。
- 导出计划与最终确认。

### 9.3 测试

- 固定种子黄金输出。
- 预览与导出一致性。
- 增强极端参数和大图片内存预算。
- 所有命名字段缺失、格式和冲突策略。
- 干净导出与增强导出数量和血缘关系。

### 9.4 退出条件

- PRD `AC-010`、`AC-011`、`AC-012` 通过。
- 默认仍为干净导出，增强必须显式选择。
- 每张增强成品可追溯到候选图、源素材、配方、种子和实际参数。

## 10. M6：恢复、性能、安装与内部发布

### 10.1 工作项

- 完整任务状态机、阶段检查点和恢复。
- 缓存 DAG 和精确失效。
- 任务并发、内存预算、缩略图优先级和错误隔离。
- 性能基线和热点优化。
- Windows 10/11、DPI 和主题视觉测试。
- Tauri 标准安装包和便携版。
- WebView2 检测和引导安装。
- 精简 FFmpeg 资源校验和许可证清单。
- 项目升级备份和数据库迁移。
- 内部发布说明、已知问题和故障诊断导出。

### 10.2 退出条件

- PRD `AC-001`、`AC-013`、`AC-014` 通过。
- 所有 15 条 PRD 验收标准通过。
- 推荐硬件普通任务内存低于 4 GB。
- 缓存命中预览切换达到或接近 300 ms 目标，并记录实际基线。
- 标准安装包接近 40-70 MB；偏差有明确依赖和 ADR 说明。
- 卸载不删除项目和导出数据。

## 11. M7：MVP 后扩展

### 11.1 MCP

- 任务创建、状态和取消。
- 允许目录、权限和审计。
- 导出和缓存清理确认令牌。

### 11.2 高级增强

- 增强执行器协议和隔离进程。
- Albumentations 环境安装、版本检测和能力声明。
- 弹性、网格、光学形变、天气和 FDA。
- 插件失败不影响基础 Rust 执行器。

## 12. 跨阶段工作流

### 12.1 文档维护

- 领域词汇改变时立即更新 `CONTEXT.md`。
- 难以逆转且有真实取舍的决定写 ADR。
- 行为改变必须更新 PRD 需求、验收标准和测试映射。
- 数据库和导出清单 Schema 必须保留版本说明。

### 12.2 代码质量门槛

- Rust 格式化和 Clippy 无阻塞警告。
- TypeScript 严格模式。
- 领域规则单元测试。
- 媒体与图片黄金测试。
- 前端布局和主题截图测试。
- 发布构建包含许可证、FFmpeg 版本和数据库迁移测试。

### 12.3 Definition of Done

一个功能只有同时满足以下条件才完成：

- 对应 PRD 行为已经实现。
- 错误、空状态、取消和恢复路径已考虑。
- 单元或集成测试覆盖关键规则。
- UI 在浅色/深色和目标窗口尺寸验证。
- 不修改源素材，不绕过路径边界。
- 任务和追溯记录包含必要参数版本。
- 相关文档已更新。

## 13. 建议首批开发任务

1. 初始化 workspace、Tauri/Svelte 和 CI。
2. 建立领域 ID、错误类型、任务状态机和应用服务端口。
3. 建立 SQLite 迁移和项目创建/打开。
4. 建立 ffprobe/ffmpeg 原型与测试素材。
5. 建立图片解码、EXIF、缩略图和虚拟网格原型。
6. 建立 Tauri 命令和前端事件协议。
7. 验证精简 FFmpeg 构建体积和许可证。
8. 完成 M0 风险评审后再进入完整功能开发。
