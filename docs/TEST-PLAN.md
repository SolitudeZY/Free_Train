# Free-Train 测试计划

## 1. 测试目标

- 保证源素材不可变和导出不静默覆盖。
- 保证视频时间戳、ROI、切片坐标和命名结果正确。
- 保证质量与相似分析可解释、可复现、可撤销。
- 保证增强预览和最终导出在相同配方与种子下保持一致。
- 保证长任务可取消、可恢复，单文件失败不破坏批次。
- 保证现代桌面界面在常见分辨率下无重叠、空白或布局跳动。

## 2. 测试层次

### 2.1 Rust 单元测试

- 领域状态机和人工决策优先级。
- ROI 边界和半开区间坐标。
- 切片网格、重叠、贴边、填充和丢弃策略。
- 拍摄时间回退顺序和证据来源。
- 命名模板解析、格式化、非法字符和冲突策略。
- 缓存键和参数失效传播。
- 质量测量函数。
- pHash 距离、SSIM 确认和相似组连通分量。
- 代表图确定性评分和平分规则。
- 增强配方校验、概率、顺序和随机种子。
- 路径规范化和允许目录检查。

### 2.2 Rust 集成测试

- SQLite 迁移、事务、项目锁和中断恢复。
- FFprobe JSON 解析。
- FFmpeg 指定时间、顺序扫描和变帧率时间戳。
- 图片解码、EXIF 方向、ROI、切片、编码和内容哈希。
- 任务队列、并发限制、取消和失败隔离。
- 原子导出和清单提交。
- 应用服务 DTO 与错误码稳定性。

### 2.3 前端测试

- Svelte 组件使用 Vitest 和 Testing Library。
- 素材树、三栏布局、参数检查器和任务状态。
- 缩略图虚拟列表和选择稳定性。
- 视频时间轴标记、人工抽帧和有效片段编辑。
- 浅白排除蒙层、锁定状态和多选操作。
- 命名模板实时示例与错误提示。
- 浅色/深色主题和键盘焦点。

### 2.4 桌面端到端测试

- 使用 Tauri WebDriver/tauri-driver 或等效 Windows 桌面自动化执行关键路径。
- 前端开发服务器额外使用 Playwright 做布局、主题和截图回归。
- 安装包、首次启动、WebView2 检测、项目创建和便携版运行需要真实 Windows 环境验证。

## 3. 测试素材矩阵

### 3.1 视频素材

- H.264 MP4：1080p、4K。
- H.265/HEVC MP4 或 MOV。
- 可变帧率视频。
- 带旋转元数据的手机视频。
- 无创建时间、错误创建时间和文件名可解析时间的视频。
- 短视频、数小时长视频。
- 部分损坏、截断、零字节和不支持编码的视频。
- 固定摄像头低变化视频。
- 运动目标只出现数秒的视频。

### 3.2 图片素材

- JPEG、PNG、BMP、TIFF、WebP。
- EXIF 旋转 1-8。
- 灰度、RGB、RGBA。
- 极宽、极高、小尺寸和混合分辨率。
- 中文路径、空格、长路径和保留名称边界。
- 模糊、过曝、欠曝、纯色、低纹理和压缩严重图片。
- 内容完全相同但文件名不同的图片。
- 轻微亮度变化、缩放、压缩和裁切后的近重复图片。

### 3.3 黄金数据

- 固定输入和配置对应的切片坐标 JSON。
- 固定视频对应的抽帧时间戳列表。
- 固定图片对对应的 pHash 距离和 SSIM 值。
- 固定增强配方和种子对应的输出哈希或容差图像。
- 固定命名模板对应的文件名列表。

黄金数据变化必须由明确算法版本变更触发，不能在测试失败时随意更新。

## 4. 关键属性测试

使用属性测试或大量随机案例验证：

- 所有切片源坐标始终位于 ROI 或明确的填充区域。
- 重叠率为 0 时相邻完整切片不交叠。
- 贴边策略覆盖 ROI 末端且不会产生负坐标。
- 命名清理后不包含 Windows 非法字符和保留文件名。
- 不同候选图片在追加序号策略下不会得到同一路径。
- 同一增强种子和配方输出一致；不同变体序号产生独立随机流。
- 人工锁定决策不会被自动质量或相似重算覆盖。
- 缓存失效只影响参数依赖的下游阶段。

## 5. 算法测试

### 5.1 变化触发抽帧

- 静态片段只按最大兜底间隔抽取。
- 短时运动片段产生变化峰值候选。
- 最小间隔限制不会重复抽取相邻峰值。
- 使用 ROI 后，ROI 外变化不影响结果。
- 预览时间点与最终抽帧时间点一致。

### 5.2 质量分析

- 指标在不同分辨率和颜色空间下保持合理单调性。
- 阈值变化只改变自动建议，不覆盖人工状态。
- 质量分布统计与逐图测量一致。
- 解码失败只影响对应候选或来源。
- 当前覆盖：纯色图低信息量与零清晰边缘方差；质量重算后人工状态保持。

### 5.3 相似分析

- 完全相同内容总能通过 SHA-256 识别。
- 轻微压缩或光照变化进入预期相似组。
- 不同来源、ROI 或切片位置默认不会互相比较。
- 高级跨范围模式必须显式启用。
- 相似关系传递产生稳定连通组。
- 同一组重复运行选择相同代表图。
- 锁定候选图优先规则正确。
- 当前覆盖：完全重复静态图片的稳定相似组、锁定代表图、人工排除导出跳过和源文件哈希不变。

### 5.3.1 审核审计与批量来源管理

- 每个审核操作写入前后状态和本地操作人。
- 撤销与重做恢复同一组的代表图、锁定和人工决定。
- 项目级全选不受左侧分段渲染限制。
- 来源组复选覆盖该组所有来源，而不是只覆盖当前可见行。
- 大批量来源删除必须从 `0 / N` 到 `N / N` 产生进度事件，并保留原始文件。

### 5.4 增强

- 所有操作验证参数边界。
- 预览与导出共用同一实现路径。
- 图片尺寸、颜色通道和编码结果符合配方。
- 极端参数不会导致崩溃、NaN 或越界。
- 每张输出写入真实执行参数和血缘组标识。

## 6. 任务与恢复测试

- 在抽帧、切图、质量、相似和导出阶段分别强制终止应用。
- 重启后能够识别中断阶段并继续。
- 已完成且缓存键未变化的阶段不重复执行。
- 修改 ROI 后只重跑 ROI 及下游阶段。
- 修改命名模板后不重新解码视频。
- 磁盘写满时停止新写入并保留可恢复状态。
- 取消 FFmpeg 任务后无遗留进程和错误成功状态。
- 单个损坏视频不影响同任务其他视频完成。

## 7. 文件安全测试

- 处理前后源素材内容哈希不变。
- 缓存清理不能删除源素材、项目数据库或导出目录。
- 导出路径穿越、符号链接和 Windows 设备路径被拒绝。
- 重名策略从不静默覆盖现有文件。
- 临时导出失败不留下被当作完成品的目标文件。
- 文件重新定位使用指纹校验，不仅按文件名匹配。

## 8. UI 与视觉测试

### 8.1 视口

- 1100×700 最小桌面窗口。
- 1366×768 常见笔记本。
- 1920×1080 标准桌面。
- 2560×1440 高分辨率。
- Windows 125%、150% 和 200% 缩放。

### 8.2 检查项

- 视频画面、时间轴、工具栏和参数面板不重叠。
- 最长中文字段和路径不溢出按钮或表格。
- 面板折叠后主操作仍可访问。
- 缩略图加载、蒙层和状态图标不改变网格尺寸。
- 浅色与深色主题下文字、焦点和排除蒙层对比度足够。
- 图片预览非空、ROI 边框位置正确、拖动交互与坐标同步。
- 任务进度、错误和取消状态不遮挡其他主要内容。

## 9. 性能测试

在推荐硬件建立以下基线：

- 1080p/4K 视频探测和顺序扫描吞吐。
- 固定间隔与变化触发抽帧吞吐。
- 不同切片尺寸和重叠率的图片吞吐。
- 10,000、100,000 候选图的缩略图浏览和数据库分页。
- pHash 候选检索与 SSIM 确认耗时。
- 任务并发度对 CPU、内存和磁盘的影响。
- 缓存命中时预览切换延迟，目标低于 300 ms。
- 普通任务内存目标低于 4 GB。

性能测试必须记录硬件、FFmpeg 构建、编码格式、分辨率和软件版本。

## 10. 安装与升级测试

- 已有 WebView2 的 Windows 安装。
- 缺少 WebView2 时的引导安装。
- 无网络且缺少 WebView2 时给出明确失败信息。
- 标准安装包和便携版启动。
- 中文安装路径和非管理员目录。
- 升级前数据库备份和迁移。
- 新版本打开旧项目，迁移失败时保留原数据库。
- 卸载不删除用户项目和导出数据。
