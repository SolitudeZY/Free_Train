# M4 质量、相似与审核实现报告

## 本次交付

M4 首个纵向版本已接通静态原图和视频候选的质量、相似、审核与导出：

- 分辨率、宽高比、Laplacian 方差清晰度、欠曝/过曝比例、灰度熵和低信息量测量。
- 可配置质量阈值，自动结果只产生保留、警告、建议排除或失败状态。
- 项目级 SHA-256 精确重复、pHash 召回、SSIM 确认和图连通分量相似组。
- 同一来源、来源组和全项目比较范围，以及视频时间窗口和比较次数安全上限。
- 基于质量分数的确定性代表图；锁定项优先，多锁定项产生显式冲突。
- 人工保留、排除、恢复、锁定、解锁和更换代表图，并保存审计事件。
- 人工保留、排除、恢复、锁定和解锁支持持久化撤销/重做；新的审核操作会清除 redo 分支。
- 审核网格状态筛选、来源筛选、相似组筛选、批量复选和分段渲染。
- 阈值分布条、阈值线、预计影响数量、阈值附近样本和清晰度/曝光/信息量/分辨率排序。
- 建议排除浅白蒙层、人工排除标记、代表图绿色边框及非颜色状态图标。
- 导出计划跳过人工排除项；自动建议未经确认不会改变导出资格。
- 相似组双击进入并排对比，组成员使用稳定尺寸视窗横向排列；滚轮、缩放滑杆和拖动分别对整组同步缩放/平移。
- 对比视图支持复选排除、整组保留、代表图切换、锁定冲突提示，并保留右侧审核详情。
- 代表图切换记录整组前后快照，支持组级撤销与重做；旧版单图代表审计记录保持兼容且不会被误解析。
- 审核汇总栏支持一键将项目内全部“建议排除”转换为人工排除，便于处理重复抽帧产生的大批近重复图片。
- 根据 M0-M4 多轮运行反馈，审核工具栏、汇总、缩略图标题、指标图、解释文字、详情与并排对比字号整体上调；紧凑布局不再以 8-9px 作为主要信息字号。
- 审核汇总栏可把当前审核项所属素材直接交接到导出页，并默认选择“审核后保留”；导出计划跳过人工排除项，但未经确认的自动建议和未审核素材仍保持可导出。
- 顶部原“快速处理”改名为“质量审核”，避免暗示已经自动串联抽帧；完整快速处理流水线仍保留在后续 M4 工作项。

## 数据与架构

- storage Schema 升级，新增 `quality_assessments`、`review_assets`、`review_audit_events` 和 `review_redo_events`。
- `image-pipeline` 负责可复用的客观质量测量、pHash 和 SSIM。
- application 统一构造静态图片与视频候选审核资产，负责分组、代表图和人工状态优先级。
- 自动分析重算只更新自动状态和相似关系，保留已有人工决定与锁定状态。
- 删除来源或视频候选时，关联质量、审核与审计记录通过外键同步清理。
- 所有审核状态只存在于项目数据库，不修改或删除源素材。

## 验证

- 质量指标测试验证纯色图片具有高低信息量分数和零清晰边缘方差。
- 应用层测试验证完全重复图片形成一个相似组并稳定选择一个代表图。
- 锁定非代表图后重算，锁定项成为代表图；人工排除状态在重算后保持。
- 审核排除可撤销和重做，状态恢复后导出资格同步恢复。
- 导出测试验证人工排除项被跳过，自动建议仍需人工确认。
- 测试同时验证分析、审核和导出前后源图片 SHA-256 不变。
- 审核页阈值输入、分布条和排序使用已持久化测量值，不会在输入变化时静默写入人工决定。
- 审核并排对比、同步缩放/平移、复选排除和代表图组级撤销/重做通过前端类型检查与 Rust 集成回归测试。
- 抽帧长任务期间切换审核不再等待全局项目会话锁；审核工作区读取和分析使用独立数据库路径句柄，进度与审核忙碌状态分别维护。
- Svelte 严格检查和 Tauri 桌面端编译通过。

## 后续边界

下一批 M4 工作将补充更大规模候选的虚拟滚动、基于 `prepared_images` 的切片级审核，以及快速处理串联至抽帧、ROI/切图、质量和审核的完整流水线。当前切片仍是可重建的预览/导出计划，不使用临时预览路径创建不可恢复的审核状态。
