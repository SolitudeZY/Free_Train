# M4 质量、相似与审核实现报告

当前状态：M4 已完成。工程实现、自动化门禁与真实素材 Windows 人工验收均已通过。阶段判定见 `M4-GATE-REVIEW.md`。

## 本次交付

M4 首个纵向版本已接通静态原图和视频候选的质量、相似、审核与导出：

- 分辨率、宽高比、Laplacian 方差清晰度、欠曝/过曝比例、灰度熵和低信息量测量。
- 可配置质量阈值，自动结果只产生保留、警告、建议排除或失败状态。
- 项目级 SHA-256 精确重复、pHash 召回、SSIM 确认和图连通分量相似组。
- 同一来源、来源组和全项目比较范围，以及视频时间窗口和比较次数安全上限。
- 基于质量分数的确定性代表图；锁定项优先，多锁定项产生显式冲突。
- 人工保留、排除、恢复、锁定、解锁和更换代表图，并保存审计事件。
- 人工保留、排除、恢复、锁定和解锁支持持久化撤销/重做；新的审核操作会清除 redo 分支。
- 审核网格状态筛选、来源筛选、相似组筛选、批量复选和分段渲染。
- 阈值分布条、阈值线、预计影响数量、阈值附近样本和清晰度/曝光/信息量/分辨率排序。
- 建议排除浅白蒙层、人工排除标记、代表图绿色边框及非颜色状态图标。
- 导出计划跳过人工排除项；自动建议未经确认不会改变导出资格。
- 相似组双击进入并排对比，组成员使用稳定尺寸视窗横向排列；滚轮、缩放滑杆和拖动分别对整组同步缩放/平移。
- 对比视图支持复选排除、整组保留、代表图切换、锁定冲突提示，并保留右侧审核详情。
- 代表图切换记录整组前后快照，支持组级撤销与重做；旧版单图代表审计记录保持兼容且不会被误解析。
- 审核汇总栏支持一键将项目内全部“建议排除”转换为人工排除，便于处理重复抽帧产生的大批近重复图片。
- 根据 M0-M4 多轮运行反馈，审核工具栏、汇总、缩略图标题、指标图、解释文字、详情与并排对比字号整体上调；紧凑布局不再以 8-9px 作为主要信息字号。
- 审核汇总栏可把当前审核项所属素材直接交接到导出页，并默认选择“审核后保留”；导出计划跳过人工排除项，但未经确认的自动建议和未审核素材仍保持可导出。
- 大批量图片导入改为最多 4 路受控解码、每 64 张单事务提交；项目已有来源在内存索引中匹配，避免每张图片重复打开 SQLite 连接和独立提交事务。
- 递归扫描每发现 256 个文件上报一次不确定进度；处理阶段显示精确总数。素材读取上限由 10,000 提升到 100,000，左侧仍按每批 500 条分段呈现。
- 已导入且路径、大小、修改时间和缩略图均未变化的素材走快速续跑，不重复解码或重建缩略图；取消后重新导入同一目录只需重点处理未完成部分。
- 导入完成后的完整 SHA-256 补算每轮最多处理 256 张，避免 20,000 张导入完成后继续长时间占满磁盘；质量分析仍使用独立内容哈希保证重复检测准确性。
- 导入、来源移除、视频抽帧和图片导出进度卡均支持暂停/继续与取消。取消保留已经原子完成的项目结果，不修改源素材；导出取消后提交仅包含已完成文件的有效 JSONL 清单。
- 长任务控制器独立于项目会话锁，任务占用项目写会话时控制按钮仍能立即登记暂停或取消请求。同一时间只允许一个受控长任务，避免多路解码和导出争抢磁盘与内存。
- Schema 迁移版本 6 新增稳定 `prepared_images`：切片以来源/候选、ROI、渲染参数、行列位置形成稳定键和项目内缓存。
- ROI 参数不变时复用稳定切片；参数变化、ROI 删除、取消或失败会清理失效缓存和对应自动审核状态。
- 某来源存在稳定切片时，正式审核只呈现该来源切片，避免原图/候选和切片重复出现。
- 切片近似和精确重复默认只在相同 ROI 名、行、列内分组；原图/候选仍保留项目级 SHA-256 精确去重语义。
- “审核后保留”切片导出按 `prepared_images.asset_key` 跳过人工排除项，不再回退到来源级状态。
- 正式审核网格改为窗口化虚拟滚动，视口上下各保留少量超扫描行；100,000 项测试覆盖首尾窗口和有界 DOM 数量。
- 顶部“快速处理”按当前范围串联必要抽帧、稳定切片准备和质量/相似分析，完成后停在审核工作台且不自动导出。
- 快速处理和单独审核均提供进度、暂停/继续与取消；审核与抽帧、导入、导出使用统一长任务互斥，不再等待项目锁造成窗口假死。
- 完全相同资产按安全分区线性连接，避免重复集合内部进行平方级精确比较。
- ROI 栏目切换素材时，已保存配置会自动为当前素材恢复或生成切片预览；底部不再无提示回退为项目素材条。预览按来源和视频候选缓存，配置变更、ROI 删除或候选删除后精确失效。
- ROI 操作改为“应用并预览”和“进入批量导出”：预览只用于当前素材抽样验算，不再作为批量导出的强制前置条件。
- 来源组 ROI 保存后明确显示影响素材数量；一次配置可供同来源组图片批量切图，来源级配置仍可覆盖个别素材。
- 导出范围新增“已选素材”，左侧复选框可直接定义任意同类型素材批次；来源组和当前素材范围保持可用。
- 快速处理的质量/相似审核严格使用本次选中来源范围，操作、撤销和重做后仍返回同一范围；范围外人工决定和质量指标保持不变。

## 数据与架构

- storage Schema 升级至版本 6，新增 `quality_assessments`、`review_assets`、`review_audit_events`、`review_redo_events` 和 `prepared_images`。
- `image-pipeline` 负责可复用的客观质量测量、pHash 和 SSIM。
- application 统一构造静态图片与视频候选审核资产，负责分组、代表图和人工状态优先级。
- 自动分析重算只更新自动状态和相似关系，保留已有人工决定与锁定状态。
- 删除来源或视频候选时，关联质量、审核与审计记录通过外键同步清理。
- 所有审核状态只存在于项目数据库，不修改或删除源素材。

- 审核排除可撤销和重做，状态恢复后导出资格同步恢复。

- 切片导出测试验证人工排除 1 个稳定切片后，“审核后保留”计划从 4 张降为 3 张。

## 后续边界

M5 必须以 `prepared_images.asset_key` 作为增强输入身份，不得使用临时切片预览路径。后续若发现 M4 回归，优先修复后再继续依赖该行为的 M5 功能。

长任务暂停是安全检查点语义：目录扫描按目录项，导入按最多 64 张批次，导出按图片，来源移除按来源，逐帧抽帧按帧响应。单个 FFmpeg 顺序解码批次在下一次媒体进度回报时响应控制请求；暂停或取消会终止该临时媒体进程并清理批次目录，继续后重新开始尚未提交的当前解码批次。
